# DealerConnect AI

**DealerConnect AI** is an AI-powered local product discovery platform that helps customers find products available at nearby local shops using their **PIN code or location**.

Instead of searching through multiple stores manually, users can discover nearby dealers, check product availability, compare local prices, view shop details, and get directions.

> **Bring local shops online — without the tech headache.**

---

## 🚀 Features

### 👤 Customer

* Search for products using PIN code or location
* Find nearby shops that have the required product
* Check product availability
* Compare prices from local dealers
* View shop address and contact details
* Get directions using Google Maps
* Send enquiries to dealers
* Save favorite products and shops
* Receive notifications
* AI-powered product search assistance

### 🏪 Dealer

* Register your local shop
* Manage shop information
* Add products to available inventory
* Update product availability and quantity
* Add product images and details
* Receive customer enquiries
* Manage shop listings

### 🛡️ Admin

* Approve and manage dealer registrations
* Create and manage master products
* Manage categories and brands
* Monitor searches and platform activity
* Manage product and dealer information
* Review platform analytics

```text
Customer enters PIN / Location

            ↓

            ↓
 Views Shop Details
            ↓
 Contacts Dealer / Gets Directions
```

## 💡 Problem We Solve

Customers often visit multiple shops or make several phone calls to find a specific product.

At the same time, many local shops have products available but lack a simple digital platform to showcase their inventory.

**DealerConnect AI connects customers with nearby local dealers and makes local product discovery easier.**

## 📱 Platform

DealerConnect AI is designed as a **web-first platform with an app-ready architecture**, allowing users to maintain the same account, profile, searches, favorites, enquiries, and preferences across platforms.

---

## 🚚 Delivery

DealerConnect AI **does not manage or provide delivery services**.

If a local dealer provides delivery, the delivery is handled independently by that dealer according to their own terms and availability.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate to the project:

```bash
cd dealerconnectai
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add your required environment variables.

Example:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🔒 Security

Do not commit sensitive information such as:
